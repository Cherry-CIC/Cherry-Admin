# Cherry Admin

React + TypeScript operations console for Cherry.

## Tech stack

- React
- TypeScript
- Vite
- TanStack Table
- TanStack Query
- Firebase Authentication
- CSS for application styling

## Local development

```bash
cp .env.example .env.local
npm install
npm run dev
```

Local development uses the dev backend by default.
